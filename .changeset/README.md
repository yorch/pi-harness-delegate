# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a way to manage versioning and changelogs. More info at <https://github.com/changesets/changesets>

- Run `bun changeset` (or `npx changeset`) in the repository root to create a changeset file. Commit the generated `.md` file.
- Every PR that touches publishable code needs a changeset. For no-user-visible changes (docs, CI, tests) use `bun changeset --empty`.
- The `chore: version packages` PR is the approval gate — nothing reaches npm without merging it.

The release workflow (`release.yml`) turns changesets into version bumps + CHANGELOG entries + `npm publish`.

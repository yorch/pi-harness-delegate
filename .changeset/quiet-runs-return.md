Run records, history filters, rerun, fan-out resume and template variables. Every run now writes a versioned JSON sidecar next to its transcript (never storing the verify command, `allowDangerous`, env or secrets; written atomically, capped at 64 KB, never through a symlink); `/delegate history` gains `--failed`/`--ok`/`--since=`/`--limit=`/`--mode=` (a repeated option or a rolled-over date is an error; the interactive list is numbered like the plain one); `/delegate rerun [n|runId]` repeats a recorded run through the normal command path. Run records are treated as untrusted data: only a record beside its own transcript in its own harness's directory is ever selected (ordered by transcript mtime, like history), a UI session always shows the plan and asks before anything runs (headless needs an explicit run id), stored `addDirs` outside the project need their own confirmation, a stored timeout/budget can only narrow the configured one, a template widened since the run is refused, and a truncated task or scope cannot be rerun; `allowDangerous`/`verify` are never replayed, and a fresh session starts unless `--resume`. `--resume=fan_…` (and the tool's `resumeFanout`) resumes every member of a past fan-out on its own harness with its own session; a member with no mapping fails (never silently starts fresh) and an unreadable member is listed in the report. Template bodies may position `{{task}}`, `{{scope}}` (the delimited block), `{{cwd}}`, `{{harness}}` and `{{mode}}`. **Behaviour change:** a template that already contains a literal `{{task}}`, `{{scope}}`, `{{cwd}}`, `{{harness}}` or `{{mode}}` now has it substituted (spaces/tabs inside the braces are tolerated, a newline is not; a placeholder used more than 16 times, or a repeated one expanding the prompt past 2 MB, refuses the run). `pruneOutputs` now only deletes sidecars named like the ones the extension writes, so a `.json` you keep in an outputs directory is no longer removed. Confirmation dialogs, validation errors, history rows and fan-out reports escape control, bidi and zero-width characters in anything that came from a record, the model or a template.

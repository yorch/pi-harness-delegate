Why this exists

One tool, four harnesses

delegate { harness:claude|codex|opencode|amp} — same task, same streaming, per-harness runners under extensions/harnesses/.

/delegate · /claude · /codex · /opencode · /amp

Normalized permissions

readonly → edit → danger maps to each harness native. danger only via allowDangerous:true — never a default.

review/plan = readonly · implement = edit

Portable templates

Markdown with frontmatter in templates/shared + templates/<harness>. User/project overlays win on collision.

harness frontmatter selects model

Streaming + transcripts

Live feed (tool ✓/✗, thinking, text tail), framed overlay (m minimize, double-esc cancel), full transcript partitioned by harness.

outputs/<harness>/<ts>-<mode>.md

Cost-aware

Tokens, context% and spend flow into pi footer stats via tool Usage. Per-harness `modelAliases`.

economy / balanced / max

pi-native UX

Footer chip, markdown renderer, `/delegate list|history`, resume via --resume, `scope:diff|pr` from pi’s git.

before_agent_start injection

Harnesses

Harness Binary readonly edit danger Notes
claude claude plan acceptEdits bypassPermissions stream-json + modelUsage context
codex codex read-only workspace-write danger-full-access exec --json, tolerant parser
opencode opencode read-only allow-edit danger run --format json
amp (omp) amp read-only workspace danger --output jsonl

Native escape hatch: permission: dontAsk / sandbox: … in frontmatter overrides normalized (must still pass allowDangerous for danger).

Usage

// agent-driven
delegate({
  harness: "codex",
  mode: "review",
  task: "review the auth diff",
  scope: "diff"
})

// slash — harness as first word
/delegate codex review the auth flow
/codex review --scope=auth/
// aliases
/claude plan the migration
/opencode implement caching
/amp --mode=docs --scope=README.md …
# partitioned transcripts
~/.pi/agent/delegate/outputs/
  claude/2025-08-25-…-review.md
  codex/2025-08-25-…-plan.md

# resume
/delegate --resume=<id> follow up
/codex --resume=<id> fix nits

# config (settings.json)
{ "delegate": {
  "defaultHarness":"claude",
  "harnesses":{ "codex":{"model":"gpt-5"} }
}}

Modes

Mode Permission Purpose
review readonly Code review, cites file:line, prioritized
plan readonly Implementation plan + risks
implement edit Edits + checks
security-audit readonly Injection/auth/secrets/supply chain
docs edit Docs matching repo style
general edit Any task
